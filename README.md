# 当前测试：私有草稿保存 + GitHub

当前使用本机登录保存服务，不调用腾讯云。首页是 `portfolio-test/0.design 首页/index.html`。

## 保存规则

- 自动保存仅写入当前浏览器 IndexedDB；点击“保存”或 Cmd/Ctrl+S，将完整编辑数据、图片、简历、作品原件、原始链接及制作备注保存到私有资料仓库 `lkbDesigner/yepian-template-editor-data`。
- 点击保存保持“编辑中”。点击“上传审核”后进入“审核中”。均不生成公开 HTML、不更新旧网页。管理员在审核稿上编辑并审核通过后，用户可以发布指定审核版本。
- 旧的“提交 HTML 即发布”请求会被拒绝；旧 Sunday `/api/save` 公开保存路由已停用。旧公开网页只保留查看入口。
- 每次上传前确认资料仓库为私有；服务端固定仓库及账号路径，不接受客户端指定用户归属或仓库。附件引用带账号和模板绑定校验，其他账号无法通过猜测 SHA 读取。
- 附件单独上传，草稿 JSON 保存引用。图片/简历沿用界面 10 MB 限制，制作附件单个最多 50 MB，单模板去重后附件最多 500 MB，文字和结构 JSON 最多 4 MB。
- 保存使用 Git 提交版本校验。同一模板有较新版本时，旧标签页保存返回冲突，本机修改不会清空。重复提交相同内容可安全恢复保存结果。

私有仓库目录：

```text
templates/<账号随机ID>/<草稿UUID>/
  draft.json               完整可编辑状态与附件引用
  metadata.json            标题、保存时间、编辑状态和版本
  attachments/<blob SHA>   附件原始字节
```

## 管理员身份

管理员身份只由服务端私有账号记录指定，绑定现有账号，不按客户端声明授权。注册和登录请求中的 role 字段不参与授权。登录及会话接口返回服务端角色，`/api/admin/*` 要求管理员身份；管理员登录后默认进入“审核管理”，首页主入口按服务端角色切换；从普通编辑入口登录的管理员也进入审核工作台。管理员自己的作品仍从“我的模板”明确进入。

“我的模板”始终是本人作品；“审核管理”只读取私有仓库 `reviews/<审核UUID>.json` 中明确提交的任务（含提交版本、时间及用户归属），不枚举或展示未提交草稿。普通用户和伪造前端角色均无法访问 `/api/admin/reviews`。普通用户编辑器提供“上传审核”：前端和服务端共同校验全部保留并显示的必填内容，包括文字、有效链接、图片和简历；作品集模块必须保留且至少有一个有名称的作品。每个作品的原始附件或原始资料链接至少提供一项，补充要求、风格／颜色参考保持选填。隐藏或删除的内容不参与完整性校验。

上传会先私有保存全部资料，再以同一次 Git 提交写入模板审核状态和任务记录，固定提交版本；管理员可以查看、下载原始资料，在同一份用户模板上编辑，并校验详情后审核通过。审核中的用户模板只读，允许“撤回审核并编辑”；撤回保留全部内容，管理员列表移除任务。模板版本冲突会拒绝提交，不覆盖他人更新。

## 跨 Tab 共用内容

作品集 Tab 默认四个作品，可继续增加或删除；直接使用封面和资料管理界面。首页仅展示未删除作品中的前四个，并从同一列表读取封面和内容。首页提供“管理全部作品”进入作品集。

个人标识／简历、联系与页脚、版权及首页／关于我的专业能力共用字段与条目。其他 Tab 默认只显示复用说明，可点击“编辑共用内容”修改同一份数据，简历不在联系模块重复上传；隐藏本页仅影响本页展示。审核和未编辑定位按共用字段及条目去重。原有分散的专业能力数据会迁移，优先保留非空内容；已有差异保留旧键供备份恢复，并提示用户。

## 我的模板与恢复

“我的模板”仅展示 GitHub 确认已保存且可继续编辑的本人模板，不合并历史公开网页，也不展示仅存在浏览器中的未保存记录；读取 GitHub 失败时提示重试，不用本地记录代替。编辑中统一显示“编辑中”，普通保存成功显示“已保存”。点击保存将完整资料写入 GitHub 私有仓库，管理员审核列表只包含主动上传审核的版本。浏览器内部恢复缓存继续保留，避免意外丢失未保存输入。
打开时优先检查私有仓库版本；同一版本的未保存本机修改会保留。如远端已更新且本机还有修改，本机版本另存为备份，再载入最新保存版本。文件和私人备注都参与恢复，旧缓存不会静默覆盖远端。

## 账号与服务

账号仍存放在本机 `.private/accounts.json`，密码为加盐哈希，不进入 GitHub。浏览器只保存最长 8 小时的会话令牌、手机号及到期时间。登录后首页显示手机号和退出登录；各页面、刷新和标签页共享状态。退出编辑保留登录，点击退出登录会注销会话。服务重启需重新登录，账号和草稿保留。

本机测试后台已改用 macOS 用户级 LaunchAgent，独立于聊天和终端运行。安装／更新：

```sh
npm ci --ignore-scripts
node scripts/install-test-service.mjs
```

安装前需将 cloudflared 放在 `.private/bin/cloudflared`，并确保 gh 已登录。安装器把运行代码放入 `~/Library/Application Support/YepianTestService`，避免 Documents 系统权限阻塞；首次复制原账号，更新安装时不覆盖账号。该目录 `.private/accounts.json` 是安装后的账号主存储，源码目录 `.private/runtime-install.json` 让手动启动复用它。全部留在本机，不进入 Git。

LaunchAgent 在用户登录时启动、异常退出后重启；监控 API 和通道健康，失效后重新建立通道，仅通过原子 Git 提交更新两个公开连接配置，保留其他文件。前端在旧配置失效时读取 GitHub 最新配置，避免等待 Pages 缓存刷新；注册、保存、提交审核等写操作不会自动重复发送。

运行状态和日志位于上述安装目录 `.private/runtime/`。维护命令：

```sh
launchctl print gui/$(id -u)/io.yepian.test-service
```

此方案仍是本机测试：电脑休眠、关机或断网期间不可用，永久可用需要迁移到常驻后端。

`gh` 需登录 lkbDesigner，具备两个指定仓库的读写权限。通道地址变化后，更新 `site-config.json`、`portfolio-test/3_中文_空模板/save-config.json` 及原始模板的对应配置并发布。电脑、服务、通道和网络需保持运行。

验证：`node --test server/*.test.mjs`。私有草稿测试覆盖附件字节恢复、账号隔离、私有可见性检查、旧版本冲突、幂等重试及禁止公开保存；审核测试覆盖完整性、选填豁免、原子提交、权限、附件下载、审核锁定及撤回。

# 页间 · 模板编辑器

## 访客体验

- 模板与编辑页包含六个对应模块：首屏、精选内容、品牌故事、特点与价值、资料下载、联系信息。
- 输入后即时预览，支持 PNG、JPEG、GIF、WebP 图片和 PDF。
- 访客无需填写仓库、登录 GitHub 或提供 GitHub 令牌。
- 页面与素材统一保存到 `lkbDesigner/yepian-template-editor-demo`。
- 每个浏览器草稿有独立编号和编辑凭据；编辑凭据保留在本机，仓库仅存 SHA-256 摘要。
- 本机草稿保存在 LocalStorage，文件保存在 IndexedDB。换设备或清除浏览器数据后无法继续编辑原页面。
- 仓库和生成页面公开，请只提交可公开的内容。

## 保存服务

GitHub Pages 负责前端。共享接口 `server/save-worker.mjs` 固定写入站点仓库。当前本机模式通过 `gh` 转发 GitHub API；长期云端部署则使用服务端秘密环境变量 `GITHUB_TOKEN`。

服务地址通过 `site-config.json` 的 `saveServiceUrl` 配置。当前为免注册 Cloudflare Quick Tunnel 测试模式：本机 `node server/local-server.mjs` 提供接口，`cloudflared` 将接口临时公开；使用本机已登录的 gh CLI 完成仓库写入，不提取或分发 GitHub 令牌。电脑、保存进程和通道必须保持运行。通道重启会更换地址，需要同步更新配置。

- `GET /api/status` 返回配置状态，不返回密钥。
- `POST /api/save` 接收字段和文件。访客的 Bearer 凭据用于保护自己的页面，并不是 GitHub 令牌。
- 仓库、分支和目录由服务端固定，请求不能指定其他仓库、任意路径或 HTML 代码。
- 文件类型与签名经过验证，单文件最多 5 MB，总计最多 8 MB。
- 服务端共享渲染器生成 HTML，对文字转义。
- 每次保存通过 Git Trees/Commits/Refs API 创建一条原子提交；并发更新会重试，避免覆盖其他提交。
- 删除的素材在同一次提交中移除。

## 长期云端部署时的所有者配置

创建仅授权本仓库的 Fine-grained personal access token，权限为 **Contents: Read and write**。在保存服务的运行时秘密环境变量中设置 `GITHUB_TOKEN`，重新部署以应用。不要放进前端、公开源码或聊天。配置完成前，页面会提示云端待配置，仍保留本机草稿。

服务端源码在本仓库，`wrangler.toml` 可用于 Cloudflare Workers 部署。Sites 打包构建入口也已保留。构建命令：

```sh
node scripts/bundle-save-worker.mjs /absolute/path/to/service/worker/index.js
```

API 文档：[Git Trees](https://docs.github.com/en/rest/git/trees)、[Commits](https://docs.github.com/en/rest/git/commits)、[References](https://docs.github.com/en/rest/git/refs)。

## 手机号与密码演示登录

当前本地 API 使用 `server/account-service.mjs`。先输入恰好 11 位 ASCII 数字并确认；新号码设置 8–128 位密码并再次确认后创建账号，已有号码输入密码继续编辑。查询号码不会提前注册账号。

密码以 scrypt 加盐哈希存储，区分大小写。账号记录位于本机 `.private/accounts.json`（目录 0700、文件 0600，Git 忽略），不得上传公开仓库，请私下备份。手机号未经短信验证；当前不支持自助重置密码。

每次进入编辑需重新登录，服务从 GitHub 恢复最近保存的文字、图片和 PDF。会话仅在当前网页内存保存，返回模板时撤销，最长 8 小时。刷新或关闭前请保存。账号信息与密码不会写入公开仓库；保存的页面内容仍公开。

启动 `node server/local-server.mjs` 并保持 Cloudflare 临时隧道运行。永久云部署还需迁移私有账号存储，原独立 Worker 仅是历史保存核心，不能单独部署为账号服务。

## 编辑器加载

编辑器先验证登录，再通过 `editor-loader.js` 加载模板和引擎；显示当前阶段，下载失败及超时均提供重新加载。模板结构包约 0.9 MB，原打包的示例位图已拆分至 `assets/template-media/` 并按需加载；所有原始文档可无损还原，字段编号和用户资料不变。预览与编辑器使用同一结构包。

## 作品详情职责

普通用户只编辑作品卡片展示信息，并提供原始附件或有效设计稿链接；作品详情由管理员制作。用户下拉菜单、未编辑定位及前后端上传审核完整性校验均排除 `case-*` 详情页，也不要求用户恢复旧详情页的显示状态。AI 文章编辑保持原有行为。管理员保留详情模板入口；已有详情数据不删除，继续随模板保存供管理员使用。

旧版公开网页及原有资料不删除，只退出当前模板列表。管理员个人模板列表不合并审核任务；没有个人模板时显示前往审核管理的入口。打开不可用的模板链接后，一次性说明当前链接不可用，移除地址中的失效提示参数，并根据当前是否有保存模板给出相应入口；仅清除指向该失效模板的“最近打开”指针，不清空编辑资料。

## 审核通过与发布

管理员从审核管理打开提交，按钮为“保存”“审核通过”，不提供上传审核和发布操作。管理员保存写回用户原模板和审核队列的同一次 Git 提交，不创建管理员个人副本。每个作品有独立详情（按作品 ID 路由），同一样式的多个作品也互不覆盖；管理员下拉菜单按实际作品名称列出详情，普通用户仍不编辑详情。原提交快照保留，后续编辑使用乐观版本校验；撤回后管理员旧页面不能再保存或通过。

通过前服务端检查用户展示内容、来源资料和每个有效作品的详情，审批记录固定获批版本、管理员 ID 及时间。用户看到“审核通过 · 可发布”；发布按钮此前禁用。用户本人点击发布后，服务端从固定审核快照生成网页，拒绝未审核、失效和其他账号的版本，不采用客户端 HTML。仅公开已显示的文字、链接、图片和简历；原件、制作备注、风格参考、签名引用及账号信息不进入公开网页。公开图片与简历合计限制 100 MB，原始资料仍受独立私有附件限制。

公开文件位于 `user-sites/<账号随机ID>/portfolios/<模板UUID>/`，固定 URL，图片使用审核版本目录。发布先准备资源，再持久化发布锁、原子更新公开仓库、回写私有发布状态；重试检查发布回执，不重复生成网站。服务器重启后可点击发布继续未完成步骤。GitHub Pages 仍需完成构建后链接才可访问。

用户获批／发布后继续编辑并保存实际变化，状态回到编辑中，旧审核任务标记为被后续版本取代，不能直接发布；已发布网站和链接保留，只有新审核通过并再次发布才更新。未改动的保存保留获批资格。

服务器使用固定模板和 LinkeDOM 渲染，编译字段编号及集合结构须与审核结构完全一致，否则停止发布。依赖锁定在 package-lock.json；升级本机服务前需安装依赖，安装器会复制渲染器和依赖。

## 第二个预填模板

首页前两张中文模板采用同一版式与编辑器：第一张保持空白；第二张通过 `preset=filled` 入口，在创建新草稿时使用 `template-prefill.js` 填充所有用户负责的文字、封面、图片、有效示例资料链接和真实 PDF 示例简历。既有必填字段、模块和 Tab 不会为了通过校验而隐藏。独立作品详情仍为空，继续由管理员制作，不绕过审核或自动发布。

示例内容来自固定模板的公开展示资料，不读取任何用户草稿；每次创建使用新的草稿及作品 ID，图片缓存仅限本次创建，不跨草稿携带私有附件引用。刷新或重新打开指定草稿恢复用户内容，不重复预填。`preset` 会经登录及编辑入口保留，管理员个人浏览模式继续遵循原角色规则。
