GOOD QUESTIONS

你想了解的，
都在这里。

现在开始→
我需要自己编辑作品详情吗？

你只需要编辑作品封面、填写项目资料，并为每个作品提供原始附件或有效链接。作品详情由管理员根据资料借助 AI 制作，再加入你的模板中。

“保存”和“上传审核”有什么区别？

保存会将内容与附件存入你的 GitHub 私有资料，管理员不会在审核列表看到。点击“上传审核”后，该版本才会进入管理员的审核工作台。

什么情况下可以提交审核？

所有保留且可见的必填内容都要填写完整。作品集模块不能删除或留空，每个作品需要提供原始附件或有效资料链接。标注选填的补充要求和风格参考不影响提交。

审核通过后，作品集会自动发布吗？

不会。审核通过后，你可以在“我的模板”中查看状态，再主动点击发布。若继续修改并保存内容，需要重新提交审核后发布新版本。

空白模板和已填示例有什么区别？

两者使用相同的版式与编辑功能。空白模板由你填写；已填示例提供完整的示例资料，方便体验提交审核与发布流程。每次新建都会生成独立副本。
